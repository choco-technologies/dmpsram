# dmpsram Documentation

The driver of the external RAM (PSRAM): a DMDRVI driver for dmdevfs with a port per chip family.

## Contents

- **[dmpsram.md](dmpsram.md)** - What the driver does, the configuration, the memory map
- **[api-reference.md](api-reference.md)** - ioctls and the port API
- **[port-implementation.md](port-implementation.md)** - Adding another chip family

View documentation using `dmf-man`:

```bash
dmf-man dmpsram          # Main documentation
dmf-man dmpsram api      # API reference
dmf-man dmpsram port     # Port implementation guide
```
